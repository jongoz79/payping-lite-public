Bank Notification Parsers

Ready-to-use parser rules for Malaysian banks and digital wallets. PayPing Lite reads notifications offline using regular expressions with zero cloud dependencies.

How to use in PayPing Lite: In the app, open the Bank Rules tab, tap + Add Bank Rule, then paste the JSON or choose Import Rule File (.json). You can also tap Teach PayPing this format on any captured notification in Today or History.
