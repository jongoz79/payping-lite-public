## 1. Notification Listener Service Justification

In Google Play Console, apps declaring a service bound by `android.permission.BIND_NOTIFICATION_LISTENER_SERVICE` must submit a clear declaration of how this capability serves the core functionality of the app.

### Play Console Justification Text (≤ 500 characters)

**English Submission (468 / 500 characters):**
```text
PayPing Lite is an on-device accessibility and merchant utility that announces payment notifications aloud for busy hawkers and small shop owners. The Notification Listener service is the core functionality of the app: it detects incoming payment alerts solely from apps explicitly enabled by the user, parses amounts and counterparty names locally, and reads them aloud via Text-to-Speech. All data is processed and stored strictly on-device with zero network transmission.
```

**Bahasa Melayu Alternative (474 / 500 characters):**
```text
PayPing Lite ialah utiliti perniagaan dan kebolehcapaian yang mengumumkan notifikasi bayaran masuk secara bersuara untuk penjaja dan peniaga kecil. Perkhidmatan Notification Listener adalah fungsi teras aplikasi: ia mendengar notifikasi bayaran hanya daripada aplikasi yang dipilih pengguna, mengekstrak jumlah bayaran dan nama pembayar secara setempat, lalu membacanya melalui Text-to-Speech. Semua data diproses dan disimpan di dalam peranti tanpa sebarang sambungan internet.
```

## 3. Android Manifest Permissions & Queries Audit

Based on the merged `AndroidManifest.xml` generated by Expo and `modules/payping-capture`:

### 3.1 Declared Permissions

| Permission | Source | Purpose & Justification | Play Store Policy Risk |
|---|---|---|---|
| `android.permission.BIND_NOTIFICATION_LISTENER_SERVICE` | `modules/payping-capture/android/src/main/AndroidManifest.xml` | Enforces that only the Android operating system can bind to `PayPingListenerService`. Mandatory for receiving status bar notifications. | **High Review Priority:** Covered by the declaration text and demo video above. |
| `android.permission.REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | *removed in build 301* | Removed because Google Play restricts it. The "Allow background running" button now opens App info (Android 12+, Battery → Unrestricted) or the battery optimisation list (older Android), so no permission is needed. | **None** (not requested). |
| `${applicationId}.permission.CAPTURE_EVENT` | `modules/payping-capture/android/src/main/AndroidManifest.xml` | Custom signature-level permission (`android:protectionLevel="signature"`). Secures local inter-process communication (IPC) between the background listener process (`:paypingCapture`) and the main UI process (`CaptureProvider`). | **Zero Risk:** Internal app signature permission, completely private to this package. |
| `android.permission.INTERNET` *(if present in base template)* | Expo default base manifest | While standard Expo scaffolding may inject `INTERNET` by default, PayPing Lite v3.0.0 executes **zero network calls**. Network calls are intentionally absent from all native and TypeScript modules. | **Low Risk:** Does not trigger special Play Console declarations, but can be safely removed via a config plugin if full offline-only manifest hardening is desired. |

### 3.2 Declared Package Queries (`<queries>`)

Under Android 11+ (API 30+), apps must declare package visibility to interact with other apps.

| Query Target | Declaration | Technical Justification | Avoided Restricted Permission |
|---|---|---|---|
| **Text-to-Speech Engine** | `<intent><action android:name="android.intent.action.TTS_SERVICE" /></intent>` | Allows the app to query and bind to the system Text-to-Speech engine (Google Speech Services, Samsung TTS, etc.) to speak payment alerts aloud. | Standard Android requirement. |
| **Installed Apps (Launcher)** | `<intent><action android:name="android.intent.action.MAIN" /><category android:name="android.intent.category.LAUNCHER" /></intent>` | Allows the "Captured Apps" screen to display launchable apps installed on the user's phone so the user can choose which apps to monitor. | **Avoids `QUERY_ALL_PACKAGES`:** Using the launcher query intent enables app selection without requesting `QUERY_ALL_PACKAGES`, which Google Play strictly restricts. |
